# Power Solid ERP — interactive mockup

High-fidelity clickable prototype for Power Solid workforce operations in Jubail.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

- Sign in with the prefilled director account to enter the office app
- Use employee ID `PS-1042` for the worker portal
- **Preview as…** in the user menu switches roles (prototype only)
- **العربية** switches the shell to RTL
- [Product map](http://localhost:3000/prototype) lists the main screens

Demo records are fictional. The logo is the official Power Solid mark from powersolid-intl.com.
