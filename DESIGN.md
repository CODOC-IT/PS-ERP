# Power Solid ERP — Design tokens

Operational workforce ERP for Power Solid, Jubail. Gold and charcoal industrial identity. Dense, readable, no marketing chrome.

## Color

| Token | Value | Use |
| --- | --- | --- |
| charcoal | `#111317` | Primary dark, important actions |
| nav | `#17191C` | Sidebar |
| gold | `#D2AB66` | Active nav, selected, branded highlights |
| gold-deep | `#B88E48` | Hover on gold |
| canvas | `#F5F6F8` | App background |
| surface | `#FFFFFF` | Panels, tables |
| surface-2 | `#EEF1F4` | Secondary surface, zebra, chips |
| ink | `#17191C` | Primary text |
| muted | `#59616A` | Secondary text |
| line | `#D9DEE4` | Borders |
| success | `#1F7A4D` | Approved, valid, paid |
| warning | `#A15C12` | Expiring, awaiting |
| danger | `#B42318` | Expired, overdue, blocked |
| info | `#175CD3` | Informational |

Gold is never used for body text. Gold buttons use charcoal text.

## Typography

- Headings: Archivo
- Body / UI: IBM Plex Sans
- Arabic: IBM Plex Sans Arabic

Scale: 12 labels, 13 table, 14 body, 16 card heading, 20 section, 28 page title.

## Radius

4, 6, 8, 12. Panels max 12. Pills only for statuses and avatars.

## Spacing

4, 8, 12, 16, 24, 32, 48.

## Elevation

One quiet shadow: `0 1px 2px rgba(17,19,23,0.06)`. No hairline-plus-diffuse-shadow pairing. No glow.

## Motion

150–220ms opacity/transform only. No bounce, scale-hover, pulse.
